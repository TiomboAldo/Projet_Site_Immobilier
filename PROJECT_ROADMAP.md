# Roadmap Levetimmo — Ce qui reste à faire

Basé sur l'analyse concurrentielle avec njikam.com (2026-08-30).
Niveau de complétude actuel estimé : ~47%.

## Sprint 1 — Urgences (quelques jours chacun)

| Fonctionnalité | Détail | Effort |
|---|---|---|
| **Bouton WhatsApp flottant** | Bouton fixe en bas à droite sur toutes les pages | 1h |
| **Filtres prix min/max** | Champs min/max dans la barre de recherche des biens | 1 jour |
| **Filtre surface (m²)** | Filtre surface min/max dans la recherche | ½ jour |
| **Pages légales** | CGU, politique confidentialité, mentions légales, cookies | 2–3 jours |
| **FAQ** | Questions fréquentes acheteurs, vendeurs, locataires | 1 jour |
| **Signalement d'annonce** | Bouton "Signaler" sur chaque fiche bien | 1 jour |

## Sprint 2 — Différenciateurs forts

| Fonctionnalité | Détail | Effort |
|---|---|---|
| **Types de biens commerciaux** | Bureaux, entrepôts, locaux commerciaux, salles de fête, studios | 1 jour |
| **Biens sponsorisés** | Badge "Sponsorisé" + paiement pour mise en avant | 2–3 jours |
| **Compteurs statistiques animés** | "X biens · Y villes · Z utilisateurs" sur la homepage | ½ jour |
| **Annuaire des agences** | Page publique : toutes les agences/agents vérifiés | 2 jours |
| **Badges de confiance** | "Annonces vérifiées · Transactions sécurisées · 100% camerounais" | ½ jour |

## Sprint 3 — Croissance & Rétention

| Fonctionnalité | Détail | Effort |
|---|---|---|
| **Alertes personnalisées** | Sauvegarder une recherche → notif email/SMS dès nouveau bien | 3–4 jours |
| **Estimateur de bien** | Outil de calcul de valeur selon ville, surface, type | 2 jours |
| **Blog / Guides immobiliers** | Articles titre foncier, quartiers, investissement — fort SEO | 2 jours infra |
| **Vue carte (map view)** | Basculer grille ↔ carte sur la page des biens | 2–3 jours |
| **Orange Money** | Ajouter Orange Money en plus de MTN MoMo | 2 jours |

## Futur (plus tard)

- Bilingue FR/EN (Cameroun anglophone : Bamenda, Buea, Limbe)
- Glossaire immobilier
- Pages ciblées diaspora / investisseurs
- Application mobile (PWA d'abord, puis app native)
